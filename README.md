# RemBG-Portable-WebUI 操作マニュアル

## 1. 起動
### `run.bat` をダブルクリック
コンソール画面が立ち上がります。初期化が完了するまでそのままお待ちください。

### 操作画面の表示
自動的にブラウザが立ち上がり、操作画面（WebUI）が表示されます。

---

## 2. 終了
### コンソール操作
1. コンソール上で **`Ctrl+C`** を実行します。
2. サーバーを停止して終了するか聞かれたら、**`Y` を入力して `Enter`**。（Nを入力すると続行します）
3. コンソール画面が閉じたら、ブラウザ（タブ）を閉じてください。

---

## 3. 基本的な使い方
### 画像のアップロード
編集したい画像をウィンドウ内の「入力プレビュー」エリアにドロップします。
（うまく読み込めない場合は何度か繰り返すと改善されるかもしれません。）

### モデルを選択
処理内容に合わせてAIモデルを選択します。（目安です）
**※SAM以外のモデルは初回使用時に自動ダウンロードされるため、数分程度かかる場合があります。**

| モデル名 | 得意分野・用途 | 特徴 |
| :--- | :--- | :--- |
| **birefnet-massive** | 高精度が必要な汎用（髪・半透明など） | **最重量・高精度寄り** |
| **birefnet-general-lite** | 大量一括・低スペック環境 | 軽量・高速 |
| **birefnet-portrait** | 人物ポートレート | 髪の毛など細部に強い |
| **birefnet-dis** | 顕著な前景切り出し | コントラスト強めの被写体 |
| **birefnet-hrsod** | 高解像度の顕著物体 | 大判・高精細向け |
| **isnet-general-use** | 汎用 | **精度×速度のバランス良** |
| **isnet-anime** | アニメ/イラスト | 線画・塗りの境界に最適 |
| **sam** | Segment Anything（汎用） | **別途パラメータ指定可能** |

> [!TIP]
> **Tips :** "birefnet-dis"や"isnet-anime"は、他のモデルでどうにもならない場合に使用するとうまくいくかもしれない特殊モデルです。

### 実行
`背景削除を実行` ボタンを押すと切り抜き処理が開始されます。

---

## 4. 出力
右側の出力プレビュー画面で結果を確認し、以下の設定を行ってください。

- **背景色の選択:** 透明 / 白 / 黒 から選択してください。（※透明はPNG/WebPのみ出力に反映されます）
- **形式の選択:** PNG / JPEG / WebP から選択してください。
- **ダウンロード:** `ダウンロード` ボタンを押すとブラウザの「ダウンロード」フォルダに保存されます。

---

## 5. 高度な使い方
### アルファマッティング
切り抜き方を微調整します。

| パラメータ | 効果 | 範囲・調整目安 |
| :--- | :--- | :--- |
| **Erode Size** | 前景をどれだけ削るか | 境界に背景色が残る場合に数値を上げる |
| **FG Threshold** | 「ここから前景」と判定する強さ | 240〜250程度で微調整 |
| **BG Threshold** | 「ここから背景」と判定する強さ | 10〜20程度で微調整 |

### SAMモード（Segment Anything）
モデルで `sam` を選んだ場合のみ有効なオプション設定です。

- **前景 / 背景 :** 入力プレビュー画像をクリックして前景/背景のチェックポイントを記録します。（複数可）
- **ポイントリセット :** 記録したチェックポイントをすべてクリアしてやり直します。

> [!CAUTION]
> **Tips :** どう設定してもうまくいかない事はあるので、早めに見切りをつけましょう。
